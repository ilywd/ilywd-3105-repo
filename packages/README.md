# Packages

Thư mục này chứa các gói `.3105` đã được xuất trực tiếp từ 3105 và kiểm tra
SHA-256 trước khi khai báo trong `repo.json`.

Không đưa bản nháp, file chứa token hoặc package chưa thử Restore vào thư mục này.

Bốn gói demo hiện tại nhắm tới `com.test` và thay file `Documents/ilywd/test`.
Payload có màu súng, màu viền, độ trong và độ dày viền lấy từ Color Tool gốc.
Nếu ứng dụng demo không tồn tại, 3105 sẽ
bỏ qua đích; không chuyển các gói này sang Bundle ID của ứng dụng bên thứ ba.
